3. Suggested In-Text Citations by Report Section
------------------------------------------------

Introduction / Background:
- Project planning requires scope breakdown, scheduling, and resource
  coordination (Project Management Institute, 2021).
- WBS is a recognized project management technique for decomposing project
  scope into manageable deliverables (Project Management Institute, 2019).

Problem Statement:
- Software effort estimation is difficult and remains important for project
  success because inaccurate estimates affect cost, schedule, and planning
  reliability (Trendowicz et al., 2014).

Literature Review:
- WBS can support software scope verification by organizing project scope into
  deliverable-oriented components (Hans, 2013).
- CPM provides a scheduling basis for identifying activities that control
  total project duration (Kelley & Walker, 1959).
- Machine learning techniques have been widely studied for software effort
  estimation and can improve estimation support when historical data is
  available (Mahmood et al., 2021).

System Design:
- ScaffoldPM uses WBS principles to organize the project into phases,
  activities, and tasks (Project Management Institute, 2019).
- The system represents dependencies as a directed graph and uses topological
  ordering concepts for dependency-based scheduling (NetworkX Developers,
  n.d.).

AI / NLP Methodology:
- Sentence-BERT provides semantically meaningful sentence embeddings that can
  be compared using cosine similarity (Reimers & Gurevych, 2019).
- ScaffoldPM applies this concept by comparing task descriptions and required
  skills with team member profiles.

Machine Learning Methodology:
- XGBoost is a scalable tree boosting system suitable for supervised learning
  problems (Chen & Guestrin, 2016).
- ScaffoldPM uses XGBoost regression to estimate task duration from task type,
  description length, required skills count, assignee experience, and heuristic
  estimate.

Implementation:
- FastAPI is used to build the backend API because it supports Python type
  hints, validation, and automatic API documentation (FastAPI, n.d.).
- Pydantic models are used for schema definition, parsing, validation, and
  serialization (Pydantic, n.d.).
- SQLAlchemy async ORM is used for asynchronous database operations
  (SQLAlchemy, n.d.).
- SQLite is used as a lightweight serverless database for local persistence
  (SQLite, n.d.).
- LangChain is used to connect the project workflow with LLM calls
  (LangChain, n.d.).
- OpenAI text generation is used for creating WBS content from a project scope
  document (OpenAI, n.d.).

Critical Path Analysis:
- CPM identifies tasks that directly affect overall project duration by
  analyzing task dependencies and slack (Kelley & Walker, 1959).
- NetworkX topological sorting supports ordering nodes in a directed acyclic
  graph where one task must occur before another (NetworkX Developers, n.d.).

Testing and Evaluation:
- Evaluate WBS relevance against the uploaded scope.
- Evaluate assignments against team member skill profiles.
- Evaluate duration prediction using historical task data.
- Evaluate scheduling by verifying dependency order, working-day calculations,
  and critical path output.

Conclusion:
- ScaffoldPM demonstrates how project management concepts, software effort
  estimation, NLP embeddings, and ML-based prediction can be integrated into an
  AI-assisted planning workflow.

6. Notes for Using These References Correctly
---------------------------------------------
- Use PMBOK and PMI WBS references in the project-management theory section.
- Use Hans (2013) to connect WBS specifically to software projects.
- Use Kelley and Walker (1959) for critical path method history and theory.
- Use Reimers and Gurevych (2019) for the semantic matching module.
- Use Chen and Guestrin (2016) for XGBoost and duration prediction.
- Use Boehm (1981), Trendowicz et al. (2014), and Mahmood et al. (2021) for
  software effort estimation background.
- Use official docs for implementation details, not as the main theoretical
  foundation.
- Do not cite Wikipedia in the final report unless your institution allows it;
  use the original books, papers, and official documentation listed above.
